# Migrate particle population storage to represented number in 0.4.0

[Issue #1752](https://github.com/uncscode/particula/issues/1752) owns one implementation PR. Base this work on upstream `c9b497b1c5da5e1ef6dc19e9e519c76b4cb63a0d`, after [PR #1755](https://github.com/uncscode/particula/pull/1755). That PR established density reads, a binned-density writer and a direct/indirect [consumer inventory](issue-1751-particle-population-consumers.md#owners-of-remaining-direct-references). Start with those boundaries. A search-and-replace of `concentration` would change gas fields, measurement-array APIs and inputs whose callers still supply physical densities.

## Storage contract and independent arithmetic

Each box owns a finite positive represented air volume `V[b]` in m³. The authoritative writable float64 array is `population[b,i]`. Mass is kg per particle per species, charge is per particle and material density is kg/m³ of material. Gas concentration is kg/m³ of air. A particle's material volume and a box's represented air volume enter different equations.

| Kind | Stored population P | Per-slot density | Contribution to total number density |
| --- | --- | --- | --- |
| Discrete | represented number in bin | P/V, m⁻³ | P/V |
| Continuous radius PDF | dN/dr, m⁻¹ | P/V, m⁻⁴ | hᵢ P/V, m⁻³ |
| Particle-resolved | multiplicity, possibly fractional | P/V, m⁻³ | P/V |

Here hᵢ is the trapezoidal node width on the explicit radius grid in metres. Sum contributions for number density. For species s, sum each contribution times its own slot mass mᵢₛ for kg/m³. Multiply by V for species kg per box. Per-node rate laws that already integrate over radius take the ordinate. A change in air volume alone changes densities at fixed P. An algorithm which samples particles and changes its computational volume must also account for the sampled inventory. Riemer et al. describe representative volume and particle/volume doubling or halving. Pichelstorfer et al. describe a well-mixed chamber with a size-independent dilution loss coefficient from flow and chamber volume. These are the physical bases of the separate controls below. [Riemer et al., sections 3–4](https://lagrange.mechse.illinois.edu/pubs/RiWeZaEa2009/RiWeZaEa2009.pdf) · [Pichelstorfer et al., Appendix B](https://acp.copernicus.org/articles/18/1307/2018/#APP2)

## Public compatibility decision

Recommend supporting the following bridge throughout 0.4.x. Removing it can be decided in a later release. These are proposed API decisions, not promises made by 0.3.6.

| Entry point | Proposed behavior and test |
| --- | --- |
| New raw construction and mutation | Use explicit `population=` or builder `set_population` for extensive inputs. Accept counts for bins/resolved and number per metre for a PDF. Preserve the supplied buffer's normal ownership contract. `p.population[:]` is the raw in-place writer. |
| Old constructor and writable field | Preserve the existing second positional argument and `concentration=` as legacy inputs. For resolved or exclusively unit-volume binned boxes, support legacy reads, slice writes, augmented assignment and whole-array replacement with documented deprecation. Getter returns the actual population array. A non-unit binned box, including one row in a mixed-volume batch, rejects legacy construction, reads and writes *before* returning an array or changing state. The error names `population` and `slot_concentration_density` and gives the density-to-population conversion. Reject simultaneous legacy and new inputs even if numerically equal. |
| Measured density input | Keep the documented units of each density-taking factory/builder method. Add an explicitly named density input where needed, including a route for resolved per-slot measurements. Convert to SI, broadcast to (box, slot), then multiply by `V[:, None]` exactly once. Legacy builder resolved `count` and resolved factory count inputs remain absolute. Explicit unit-bearing density setters may accept non-unit V because their units determine the meaning. Reject conflicting input forms independently of setter order. |
| Reads, units and lifetime | Keep `slot_concentration_density`, `number_density`, `species_mass_density` and `species_mass_inventory`. Keep detached derived arrays. Keep the private integrated-weight helper for condensation/optics and the independent measurement-array optics API. Validate mutable state on derived reads. A previously acquired raw NumPy reference cannot be revoked if someone later mutates V. Document it as an extensive buffer for its lifetime. |
| Untagged legacy carriers | Preserve shape-only copy/transport where currently supported. Require explicit kind before any density calculation or unit conversion. For an old untagged payload with ambiguous units, require caller-supplied interpretation or reject. Test unchanged untagged legacy round trips separately from tagged physics. |

Implement this with one stored dataclass field and an explicit initializer or equivalent signature bridge. Check positional calls, keyword calls, dataclass introspection and reconstruction, slicing, copying, recorder string lookups and in-place buffer identity. Move internal callers to canonical names before enabling deprecation warnings. Assert the expected warning on legacy calls under the repository's warnings-as-errors policy. Suppressing unrelated warnings would hide regressions. [ParticleData](../particula/particles/particle_data.py) · [Builder](../particula/particles/particle_data_builder.py) · [Initializers](../particula/particles/particle_data_initialization.py)

## Implementation order and review gates

1. **Establish CPU storage, construction and units.** In `validate_representation`, replace the exact-one guard with finite positive per-box volume. Preserve shape, dtype, grid ordering, nonnegativity, empty resolved axes and minimum PDF grid length. Decide validation timing explicitly: the current direct dataclass checks shapes in `__post_init__`, while the builder also validates the kind. Keep the untagged boundary. In the builder resolve V before translating a measurement, including when setters arrive in reverse order. Pin the defaults explicitly (unit-volume results must match 0.3.6). For newly admitted boxes recommend default one represented particle per resolved slot, default one particle/m³ per discrete bin and zero PDF ordinates. Cover `create_particle_data_from_radii`, `create_lognormal_binned_particle_data` including its late array assignment, `create_resolved_particle_data` including its existing density-to-count conversion, and `create_lognormal_resolved_particle_data`. The latter's modal densities determine *relative sampling probabilities* and it creates unit-count slots. Preserve that sampling contract and RNG consumption. Verify caller arrays survive failed shapes, units and overflow. [Native measures](../particula/particles/_population.py) · [Initializers](../particula/particles/particle_data_initialization.py)
2. **Move physical calculations and writers as pairs.** Share P/V for all kinds. In binned coagulation, form a density candidate, validate the entire extensive candidate (including overflow in V × density), then commit into the original buffer. Alternatively add V × density increment to P after staging and checking the result. Test non-unit PMF/PDF evolution against a unit-volume control, including zero duration and rejected steps. Condensation, latent heat, chemistry, optical heating and deterministic wall loss consume density for volumetric rates; per-box gas/species/energy budgets need the corresponding V. Homogeneous survival may scale P in place. Resolved merges, charge, lineage, field retirement and stochastic wall loss use actual multiplicities. For nucleation trace both proposed and admitted ledgers through gas limitation, exhaustion and birth. J in m⁻³ s⁻¹ contributes J V Δt events before limits; an already absolute event count is used directly. Preserve equal/unit-count admission and RNG state on no-op or rejected work. Check adaptive residuals/Jacobians as well as fixed-step writers. [Coagulation](../particula/dynamics/coagulation/coagulation_strategy/_native_step.py) · [Condensation](../particula/dynamics/condensation/species_mapping.py) · [Nucleation](../particula/dynamics/nucleation/particle_source.py) · [Exhaustion](../particula/particles/exhaustion.py)

For a computational sample representing a different air volume, pack P × Vcell/Vsample and unpack using the reciprocal if restoring the sample. Preserve the existing adapter's density-based mapping for legacy unit-volume samples. Make the target sample volume explicit in the template or argument; assert that a full-cell snapshot returns physical cell volumes. Do not infer sample provenance solely from V=1. On unpack preserve the destination template's per-bin mass/size coordinate wherever extensive count and species mass are both zero. For gas-only layouts handle the empty bin/material axes directly. Tests must inspect individual extensive lanes before checking round-trip agreement. Check closed and open transport budgets and the separately supported resolved communication path. Remove the binned unit-volume guards from shared and condensation-specific device admission while retaining finite-positive checks. Keep native GPU admission for discrete/resolved only. Standalone measurement optics has its own representation codes and can accept measured PDFs. In resident diagnostics, compute number density with division for both supported kinds and species inventory as Σ P m without a discrete-only V factor. Check event counts, latent energy, direct and chunked condensation, and adaptive reservoirs against independent host arrays. Exercise direct, resident, prepared and native CUDA capture, pointer stability, pending-device errors and restart continuity. Avoid adding host reads to accepted steps. ## Scientific acceptance matrix

Use volumes 0.25, 1 and 4 m³ in one batch wherever the API supports multiple boxes. For a single-box process also run three independent boxes. Compute expected values directly from the fixtures before comparing two backends.

| Risk | Fixture and observable result |
| --- | --- |
| Density conversion performed twice or along the slot axis | Two bins at [4, 8] m⁻³ give P = [1, 2], [4, 8], [16, 32]. Give the slots different species masses and optical cross sections. Each wavelength must give Σ density × cross section for both extinction and absorption. Inventories scale 1:4:16 across the boxes. One measured bin at 2 cm⁻³ represents 500,000 particles in 0.25 m³. Check both setter orders and explicit count inputs. |
| PDF node or species weights lost | Radius nodes [1, 2, 4] nm and dn/dr = [2, 4, 2] × 10⁹ m⁻⁴ give per-node number densities [1, 6, 2] m⁻³. Raw dN/dr scales with V, and the integrated represented numbers are [2.25, 9, 36]. Per-particle species masses [1, 2, 4] and [4, 1, 3] × 10⁻¹⁸ kg give densities [21, 16] × 10⁻¹⁸ kg/m³. Verify each species separately with zero or appropriately tiny absolute tolerance. Include a valid all-zero PDF, empty resolved slots, fractional multiplicities, invalid or overflowing conversions and a post-construction invalid volume. |
| Inventory/rate mismatch | Compare deterministic binned coagulation to the unit-volume density trajectory for a constant kernel and fixed composition. Verify species conservation, known number loss and rejected large-step immutability. In closed condensation, compare the change in gas density × V with the opposite sum of particle species mass changes × represented count. Check latent heat and inert lanes. For a prescribed J=8 m⁻³ s⁻¹ over 2 s the unlimited expected event counts are [4, 16, 64]. Mirror gas limitation and an absolute source test without multiplying by V again. For stochastic events use seeded ensembles with a predeclared confidence interval for the mean; reserve exact equality for same-backend restart and deterministic invariants. |
| Equal concentrations obscure different physical outcomes | Start with 100 represented particles and 1 µg gas tracer in 0.25 m³. At fixed V one clean-air half-life leaves 50 and 0.5 µg. Expanding the original resolved state to 0.50 m³ instead leaves 100 and 1 µg. Both produce 200 particles/m³ and 2 µg/m³. Follow each with the same supported deposition or condensation rate and compare intensive rates and distinct extensive budgets. Also test sample rescaling: under proportional duplication of counts and represented V, the sampled density stays constant. Keep chamber flushing in [dilution](../particula/dynamics/dilution.py), and exercise the existing resolved [prescribed-volume path](../particula/gpu/kernels/communication.py) on its supported backend. New effective-volume dilution and generalizing the public expansion operator are separate features. |
| Transport double-counts V | For [4, 3] m³ cells with gas [2, 3] kg/m³, bin densities [5, 7] m⁻³ and per-particle masses [2, 3] kg, the rows (gas kg, count, particle kg) must be [8, 20, 40] and [9, 21, 63]. Run full-cell and explicit subsample paths, and repeat with an empty class carrying a known radius and a gas-only grid. Check extensive totals before and after a closed transport step. For parcel snapshots verify both the returned volume and the recovered vapor, dry and liquid inventories at two distinct samples. |
| API or restart appears to succeed with wrong semantics | Assert object identity for legacy-valid writable readers, full-array replacement, view writes and raw no-op steps. Check that one non-unit binned row rejects the whole legacy read/write. Inspect caller arrays after rejection. Verify optional analysis observables, v1 units and new file round-trips; prove rejected legacy checkpoints leave destination bytes and RNG streams intact. Compare uninterrupted and resumed next steps, including stochastic events, on each qualified backend. |

### Baseline evidence from this worktree

At the merged 0.3.6 revision, the following selection passed **145 tests with zero skips** with the host GPU enabled. A separate run without GPU access passed 123 and skipped 22. These results qualify the starting point. The newly admitted non-unit bin/PDF cases above still require implementation.

```bash
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 python -m pytest -q --no-cov -Werror -rs \
  particula/particles/tests/{particle_population,particle_data_initialization}_test.py \
  particula/dynamics/tests/native_dilution_test.py \
  particula/coupling/tests/grid_flow_test.py particula/execution/tests/recording_test.py
```

I also exercised two current grid boundaries directly with two cells at 4 and 3 m³. With a single empty bin, pack emitted gas inventories [8, 9] kg and zero particle lanes correctly. Unpack changed the supplied reference mass from 2 to 0 kg per particle in both cells, losing the size coordinate. For a gas-only layout, unpack raised `ValueError` while reshaping zero entries to `(2, 0, -1)`. Promote both reproductions to tests in step 3.
