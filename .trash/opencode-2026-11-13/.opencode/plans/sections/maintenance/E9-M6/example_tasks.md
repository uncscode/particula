# Example Tasks

1. **P1: Reconcile final legacy-consumer inventory.** Review qualified imports,
   string aliases, builder names and M2 temporary seams across production,
   examples and tests. Attach a native replacement and test node to every row;
   block deletion if a supported consumer still constructs a facade.
2. **P2: Remove particle facade exports with positive native tests.** Delete
   obsolete representation surfaces, verify old root/package/concrete imports
   fail for the intended reason, and retain native non-unit-volume numerical
   assertions from `representation_test.py` and zero-particle cases.
3. **P3: Remove GasSpecies/Atmosphere without losing thermodynamics.** Keep
   native GasData and EnvironmentData builders, vapor-pressure science and
   mixed-gas alignment tests while deleting only obsolete facade construction.
4. **P4: Close a recorded compatibility branch.** Remove an inventoried legacy
   branch/message from a migrated CPU consumer, with adjacent native identity,
   rejection-order and failure tests. Do not delete unrelated physics warnings
   or `gpu/conversion.py` transfer helpers.
5. **P5: Prove a native composed workflow at non-unit volume.** Construct the
   M2 triple, compose M4 runnables, compare per-species results to independent
   references and verify held identity. Run both wall-loss suites and separate
   explicit-transfer/resident contract checks; do not add public GPU APIs.
6. **P6: Publish a truthful v0.3.0 closeout.** Reconcile the full M5 example
   ledger, synchronize/execute retained notebook pairs, remove stale API links,
   run strict docs/lint/full untargeted tests, and record any missing evidence
   as BLOCKED rather than marking readiness successful.

These are issue seeds aligned to the six phases, not additional tracks. Each
function change and its tests are one reviewable increment; all follow the
strict upstream completion/validation chain.
