# Example Tasks

These are issue-sized examples within the five phases, not additional tracks.

1. **P1 normalization audit:** Trace legacy concentration access and native
   consumers for discrete, continuous-PDF and particle-resolved paths. Record
   storage units and conversion equations, with V=0.25 and V=4 characterization
   fixtures. Reject a blanket raw-field substitution unless proven equivalent.
2. **P1 species decision:** Use three distinct gas lanes with mask
   `[True, False, True]` to document the particle/environment/configuration map.
   Specify how gas-only species survive and how malformed declared maps reject.
3. **P2 replacement specification:** Describe a new compatible triple that
   changes species layout: individual replacement must not publish an invalid
   intermediate layout, whereas coordinated replacement validates all three
   before publication. Hand the identity and rejection matrix to M2.
4. **P3 needed particle helper:** Given a demonstrated consumer gap, implement
   a minimal normalized quantity helper rather than storing a cached value.
   Test current-array reads, per-species population inventories and explicit
   volume semantics. Reuse `total_mass` for per-particle mass.
5. **P4 mixed-gas helper:** Validate ordered metadata and environment alignment
   without reconstructing or coercing held objects. Snapshot arrays and names
   around rejected input; verify all-false partitioning still retains all gas.
6. **P5 handoff:** Publish the bounded developer contract, run a data-only
   integration fixture, record literal required validation outcomes, and ask
   the maintainer to admit M2 only after M1 is completed and validated.
