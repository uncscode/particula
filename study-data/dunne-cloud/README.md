# Dunne CLOUD figure data

Each UTF-8 CSV contains the values drawn in the PNG with the same name. To redraw the figures, place the eight CSVs and `replot.py` in one directory and run `python replot.py --output figures` there with NumPy, pandas and Matplotlib installed. The script reads the CSVs beside it and writes eight PNGs. For the calculations that produced the CSVs, follow the [simulation source and figure-by-figure guide](https://github.com/uncscode/particula/tree/41371efa56187bc096994d6d92efb39214ee9e44/studies/dunne-cloud). These files preserve plotted observations, reference values and simulation summaries. They support replotting without a new fit or chamber simulation.

| CSV | Quantities and units |
| --- | --- |
| [formation-overview.csv](formation-overview.csv) | Measured and modeled 1.7 nm formation rates in cm⁻³ s⁻¹ at 248.3 K and 0.38 pptv ammonia. |
| [formation-bounds.csv](formation-bounds.csv) | Formation rates in cm⁻³ s⁻¹ for six withheld records and dimensionless error factors for five holdout groups. |
| [cluster-bounds.csv](cluster-bounds.csv) | Probability of reaching five acids and modeled-to-observed neutral dimer concentration ratio. Both quantities are dimensionless. |
| [transport-bounds.csv](transport-bounds.csv) | Probability of reaching 10 nm, flux at 10 nm in cm⁻³ s⁻¹ for the binary-allowed source, and fraction of simulations with zero 10 nm crossings during hours 12–18. The plot multiplies this last fraction by 100. Simulated volumes are in cm³. |
| [warm-growth-controls.csv](warm-growth-controls.csv) | Peak particle concentration at physical diameter ≥9.7 nm and later root-mean-square error (RMSE), both in cm⁻³. The peak of each simulated trajectory is taken before computing percentiles. |
| [warm-ensemble.csv](warm-ensemble.csv) | Hours since the first size measurement and observed and modeled concentrations ≥9.7 nm in cm⁻³. Each row gives the observed count and both models’ pointwise percentiles. The two displayed windows cover 0–6 h and 6.36–32.97 h. |
| [warm-paired-errors.csv](warm-paired-errors.csv) | Within-draw change in RMSE (cm⁻³) against the named comparator, for each time window at ≥9.7 nm. Negative values mean a smaller error. |
| [design-and-reference.csv](design-and-reference.csv) | Dimensionless high-to-low acid formation-rate ratios at 223 K and R² for log formation rates with fixed published coefficients. The reference column for the first panel is the observed rate ratio. The second uses the nominal calibration. |

The percentile columns give the 5th, 50th and 95th percentiles across the specified calibration and model scenarios. The cold comparisons use 128 draws, and the warm comparisons use 512. Empty fields belong to the other panel in a multi-panel CSV. In the cold tables, `line` is the source line counting the Dunne CSV header as line 1. Condition labels give temperature and sulfuric acid in 10⁶ molecules cm⁻³. In the rate comparisons, `full` allows an ammonia-independent pathway and `assisted` requires ammonia. In the warm time series, `measured` uses measured acid as the model input and `gas_matched` uses the OH + SO₂ reconstruction normalized to the early measured mean. The `observed` column is the count integrated from CLOUD particle size spectra.

The original formation rates are archived by Dunne et al. Kürten provides the SANTIAGO figure data, and the neutral dimer measurements appear in Kürten et al. (2015), Fig. 9 and Table 3. Donahue et al. provide the original run 1833 size spectra and acid history.
