# Water activity

<a id="activity-and-partitioning-examples"></a>

Activity connects mixture composition to equilibrium vapor pressure. A useful
first question is whether changing a mixing assumption materially changes the
pressure reduction for the component you care about. The examples below build
from that comparison to water uptake and condensed organic mass.

Start with ideal activity to connect composition and partial pressure. Use κ for the water-uptake question and BAT for water–organic nonideality. For a comparison with measured composition or activation, follow [Particle water uptake and activation](../../../literature/particle-water-uptake/index.md).
