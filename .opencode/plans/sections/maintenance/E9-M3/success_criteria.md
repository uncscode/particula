# Success Criteria

- [ ] M2 completion and validated revision, with M1 contracts, accepted.
- [ ] All supported native condensation rates/steps/configuration work without
  facade construction, including staggered and latent-heat paths.
- [ ] Native coagulation mechanisms, combinations, rates and binned/resolved
  steps preserve science and single-box admission.
- [ ] Neutral/charged wall loss supports existing geometries/distributions;
  BOTH normal and excluded adjacent CPU wall-loss suites explicitly pass.
- [ ] Species alignment, non-unit volumes, unequal weights, independent
  inventories, protected state and rejection have native assertions.
- [ ] Every enduring migrated assertion has a native replacement; all retained
  compatibility has a named consumer and M6 removal owner.
- [ ] Required focused checks, untargeted coverage, lint/type and applicable
  docs checks pass on the final revision. Required unavailable evidence blocks
  handoff; optional CUDA skips are recorded separately.
- [ ] Reviewed scientific evidence and native contracts handed to M4. Legacy
  deletion remains M6-only, after M5 completed and validated.
