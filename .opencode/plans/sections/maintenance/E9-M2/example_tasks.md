# Example Tasks

1. **P1 native constructor:** Translate aggregate identity assertions to native
   particle/gas/environment fixtures; assert a mixed-gas triple is held without
   reconstruction and wrong box dimensions reject without candidate changes.
2. **P2 coordinated layout change:** Build old and proposed triples with
   different approved species layouts. Show that incompatible individual
   replacement rejects but the complete compatible triple succeeds by identity.
   Fail the last candidate's validation and compare all old/candidate snapshots.
3. **P3 builder:** Replace strategy-name/count admission on the native builder
   path with M1 structural validation; preserve fluent assembly and rejection
   behavior, all gas categories and supplied identities.
4. **P4 binned preset:** Reuse lognormal PDF/PMF generation without constructing
   `ParticleRepresentation`. Migrate distribution assertions and independently
   verify radius-derived masses and physical population totals at non-unit volume.
5. **P5 resolved preset:** Use controlled sampled radii to verify mass conversion,
   density/charge broadcasting and count/volume semantics. Preserve scientific
   behavior rather than blindly copying the facade's raw concentration array.
6. **P6 handoff:** Demonstrate construction and replacement in a data-only
   integration case, publish the bounded developer contract and pass the
   required checks. List any retained temporary seam with M3/M4/M5 consumer
   migration owner and M6 removal owner; request explicit M3 gate approval.

These are phase-sized implementation examples, not extra parallel tracks or
permission to migrate downstream physics, runnables or supported tutorials early.
