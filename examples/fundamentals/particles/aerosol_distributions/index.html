      One population, different size spectra

      Section titled “One population, different size spectra”

      Why can two plots of the same aerosol population have different heights and shapes? The ordinate may describe number per unit diameter, number in a bin, or number per logarithmic interval. Recognizing that distinction is essential when comparing an instrument spectrum with a model’s initial conditions.

      Here we construct one- and two-component lognormal populations, compare a diameter density with bin-integrated numbers, and convert the density into Particula’s native radius coordinate. The calculation uses CPU NumPy arrays; familiarity with native particle construction helps with the last step. The populations are illustrative, not fitted measurements.

      Choose the size range

      Section titled “Choose the size range”

      Logarithmic spacing resolves several size decades with a manageable grid. The domain below is 0.001–10 µm in diameter. Logarithmic spacing of the points does not itself turn a density per diameter into a density per log diameter.

      Convert density to number in each bin

      Section titled “Convert density to number in each bin”

      A bin-integrated distribution stores a contribution for each interval; its total is . Particula calls this representation a PMF. Here “mass” in probability mass function does not mean particle material mass.

      The helper weights the PDF by bin widths and rescales the sum to the requested total. On a logarithmic grid, large-diameter bins are wider in linear diameter, so weighting changes the relative heights. Both plots still describe the same chosen population, within the numerical discretization.

      Compare this plot with the PDF above. Bin width is now included, so peak heights cannot be compared directly across the two ordinates. Refining the grid changes number per bin even when the underlying continuous population is unchanged.

      Recover the total with a sum

      Section titled “Recover the total with a sum”

      The PMF is already integrated over bins, so sum its entries without multiplying by bin widths again. The printed values can be compared with the earlier PDF integrals. Agreement checks consistent bookkeeping between representations.

      Carry the measure into the model

      Section titled “Carry the measure into the model”

      The useful distinction is the integration rule: integrate a density against its coordinate, or sum bin contributions. A change in plot shape can therefore come entirely from representation. Before attributing it to aerosol physics, check the coordinate, units, bin widths, and normalization.

      Native radius-PDF storage

      Section titled “Native radius-PDF storage”

      Native continuous_pdf storage uses radius in metres and . With in micrometres, , hence . Changing the coordinate requires changing the ordinate too; rescaling the horizontal axis alone would change the integral.

      For this final model construction, interpret the supplied component totals as number concentrations in m⁻³. The same numerical spectrum then has units m⁻³ µm⁻¹ before conversion and m⁻⁴ afterward. This concentration convention is an input assumption, not a volume measurement. The radius grid accompanies the stored PDF.

      What this lets you compare

      Section titled “What this lets you compare”

      The final printed native number density should retain the mixture’s supplied 2,000 m⁻³ under the stated concentration convention. The key result is that PDF, bin-integrated number, and native radius PDF require different ordinates while preserving the represented population.

      To adapt this to an instrument spectrum, first identify whether its ordinate is , , or number in a bin. For example, . Then compare integrated concentration before and after conversion, and test sensitivity to the grid and measurement range. These would be additional checks, not results established by this example. Continue to population storage or use the same representation distinction in coagulation comparisons.
