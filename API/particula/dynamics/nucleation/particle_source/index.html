    particula.dynamics.nucleation.particle_source

    Plan and atomically commit CPU particle-source transactions.

    The concrete-module-only demand planning boundary converts survival-adjusted potential event rates [#/m³/s] and a duration [s] into immutable, gas-admitted source-demand records without accessing particle capacity or mutating caller state. The source transaction boundary consumes those records, stages slot activation and exhaustion policy on a private ParticleData copy, and writes validated particle and gas arrays atomically. Source transaction scales pre-existing particle and gas concentrations for selected representative-volume rows before removing finalized source mass. Neither demand planning nor source transaction is exported through public package namespaces.

    Own immutable diagnostics from a committed source transaction source transaction.

    All arrays are fresh read-only copies. event_count_units is count for native resolved storage and m^-3 for legacy. Gas mass fields are [kg/m³]; slot counts and policy codes are int32. Native conservation residuals compare mapped particle-plus-gas density before and after, with particle-only lanes included. Legacy residuals use the scaled-domain sum.

    class ParticleSourceCommitConfig(maximum_slot_weight: float, source_charge: float, exhaustion_controls: ExhaustionControls, requested_scale: NDArray[np.float64], minimum_scale: NDArray[np.float64], minimum_volume: NDArray[np.float64], radius_cubed_relative_error: float = 1.0, mean_radius_relative_error: float = 1.0, surface_relative_error: float = 1.0, diversity_absolute_error: float = 1.0, species_map: NucleationSpeciesMap | None = None)

    Own controls and representative-volume inputs for a source transaction transaction.

    The configuration owns read-only float64 public construction sidecars. Their length is checked against the demand planning box count by commit_particle_source. The four resampling bounds intentionally require exact Python float values to match the exhaustion-policy boundary.

    minimum_scaleNDArray[np.float64]Minimum permitted representative-volume scale per box, shape (n_boxes,). This record owns a read-only float64 copy.

    def commit_particle_source(demand: SourceDemandData, diagnostics: SourceDiagnostics, particles: ParticleData, gas: GasData, config: ParticleSourceCommitConfig) -> FinalizedSourceDiagnostics

    Commit a gas-admitted source into staged fixed-capacity particle storage.

    Demand planning event counts are [#/m³]; native commits convert them to counts at the current volume. Native representative scaling preserves gas density and scales existing counts with volume. Legacy commits retain density events and scale pre-existing gas. Demand planning demand and final gas removal are mass concentrations [kg/m³], while per-event particle mass is [kg/event] and source_charge is in elementary-charge counts. Policy resolution, resampling, representative-volume scaling, and activation operate on a private ParticleData.copy(). A selected representative-volume row scales pre-existing particle and gas concentrations before final source mass is subtracted. Returned diagnostics own read-only arrays. Only caller masses, concentration, charge, volume, and gas concentration arrays are mutated, after all validation.
