    particula.dynamics.coagulation.particle_resolved_step.super_droplet_method

    Super droplet method for coagulation dynamics.

    This module implements a Super Droplet Method for coagulation dynamics, used to simulate how particles grow through collisions.

    def _bin_particles(particle_radius: NDArray[np.float64], radius_bins: NDArray[np.float64]) -> Tuple[NDArray[np.int64], NDArray[np.int64]]

    Divide the sorted particle radii into bins and count how many fall into each bin.

    This function uses radius_bins as edges and assigns each particle radius to a bin index via np.digitize. The result is (1) a histogram with the number of particles in each bin, and (2) an array of per-particle bin indices.

    radius_binsNDArray[np.float64]Edges used to define the bins.

    Returns

    NDArray[np.int64]
    number_in_bins: Counts of how many radii lie in each bin.
    NDArray[np.int64]
    bin_indices: The bin index assigned to each particle.

    Map bin-relative indices back to absolute positions in the particle array.

    This function adjusts the offsets for each bin so that the pairwise indices used for collision are mapped onto the actual sorted particle array.     _coagulation_eventsfunction#

    View source
    def _coagulation_events(small_index: NDArray[np.int64], large_index: NDArray[np.int64], kernel_values: NDArray[np.float64], kernel_max: float, generator: np.random.Generator) -> Tuple[NDArray[np.int64], NDArray[np.int64]]

    Stochastically pick which collisions (among possible pairs) actually happen.

    This function computes a collision probability for each (small_index, large_index) pair by taking the ratio of kernel_values / kernel_max. Next, a random uniform draw decides if each collision occurs.

    Parameters

    NameTypeDescription
    small_indexNDArray[np.int64]Array of indices representing smaller particles.
    large_indexNDArray[np.int64]Array of indices representing larger particles.
    kernel_valuesNDArray[np.float64]Collision kernel values for each pair.
    kernel_maxfloatA maximum kernel value used for normalization.
    generatornp.random.GeneratorRandom generator to compare probabilities vs. uniform draws.

    Returns

    NDArray[np.int64]
    Filtered small_index containing only those that coagulated.
    NDArray[np.int64]
    Filtered large_index containing only those that coagulated.

    Calculate an approximate count of particle-pair interactions.

    This function estimates the number of collisions or interactions that might occur between two bins of particles, given a maximum kernel value and the current population of each bin. When the bins are the same, a correction factor is applied to avoid double-counting pairs.

    _sample_eventsfunction#

    View source
    def _sample_events(events: float, volume: float, time_step: float, generator: np.random.Generator) -> int

    Determine how many collisions actually occur using a Poisson draw.

    This function uses the expected collision count (events) and normalizes by system volume to compute an effective collision rate. It then samples from a Poisson distribution to obtain the actual number of collisions happening within the current time_step.

    Parameters

    NameTypeDescription
    eventsfloatThe calculated number of particle pairs that could interact.
    volumefloatThe volume of the simulation space (m³).
    time_stepfloatThe time span (seconds) over which collisions are considered.
    generatornp.random.GeneratorA NumPy random Generator to sample the Poisson distribution.

    Returns

    int
    The sampled number of coagulation events as an integer.

    def _super_droplet_update_step(particle_radius: NDArray[np.float64], concentration: NDArray[np.float64], single_event_counter: NDArray[np.int64], small_index: NDArray[np.int64], large_index: NDArray[np.int64]) -> Tuple[NDArray[np.float64], NDArray[np.float64], NDArray[np.int64]]

    Update particle radii and concentrations when two particles coagulate.

    large_indexNDArray[np.int64]Indices for larger particles in a coagulation event.

    NDArray[np.float64]
    An updated array representing the concentration of particles.
    NDArray[np.int64]
    An updated array tracking the index-wise number of events.

    get_super_droplet_coagulation_stepfunction#

    View source
    def get_super_droplet_coagulation_step(particle_radius: NDArray[np.float64], particle_concentration: NDArray[np.float64], kernel: NDArray[np.float64], kernel_radius: NDArray[np.float64], volume: float, time_step: float, random_generator: np.random.Generator) -> Tuple[NDArray[np.float64], NDArray[np.float64]]

    Carry out one time-step of super-droplet-based coagulation.

    This function sorts particles by radius, bins them, and then stochastically computes collision events according to the coagulation kernel. It updates the particle radii/concentrations, then unsorts them back to the original order.

    Parameters

    NameTypeDescription
    particle_radiusNDArray[np.float64]Array of particle radii (m).
    particle_concentrationNDArray[np.float64]Array of per-particle concentration.
    kernelNDArray[np.float64]2D matrix of coagulation kernel values, dimension ~ len(kernel_radius) × len(kernel_radius).
    kernel_radiusNDArray[np.float64]Array of radius points defining the kernel dimension.
    volumefloatSystem volume or domain size in m³.
    time_stepfloatThe length of this coagulation iteration in seconds.
    random_generatornp.random.GeneratorRandom number generator for sampling collisions.

    Returns

    NDArray[np.float64]
    Updated radii array after processing coagulation.
    NDArray[np.float64]
    Updated concentrations array after processing coagulation.

    def random_choice_indices(lower_bin: int, upper_bin: int, events: int, particle_radius: NDArray[np.float64], bin_indices: NDArray[np.int64], generator: np.random.Generator) -> Tuple[NDArray[np.int64], NDArray[np.int64]]

    Select valid particle indices in two bins for coagulation events.

    This function tries to choose events valid indices from lower_bin and upper_bin, discarding any particles with radius ≤ 0. It uses the provided random generator to perform the sampling with replacement if needed.

    Parameters

    NameTypeDescription
    lower_binintIndex of the lower bin to filter particles from.
    upper_binintIndex of the upper bin to filter particles from.
    eventsintNumber of events (indices) to sample for each bin.
    particle_radiusNDArray[np.float64]Array of particle radii; only those > 0 are considered valid.
    bin_indicesNDArray[np.int64]Array of bin labels corresponding to each particle.
    generatornp.random.GeneratorRandom number generator used for index selection.

    Returns

    NDArray[np.int64]
    Indices of particles from the lower bin.
    NDArray[np.int64]
    Indices of particles from the upper bin.
