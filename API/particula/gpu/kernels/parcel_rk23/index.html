      particula.gpu.kernels.parcel_rk23

      Shared adaptive warm-parcel integration and explicit RK3(2) stages.

      The independent coordinates are p/p0 and liquid volume / dry volume per class. At every stage total water and the parcel first law determine vapor and temperature. Only scalar trial errors cross to the host during integration. The accepted trajectory uses the selected third-order method on replay.
