    particula.execution.errors

    Dependency-neutral execution capability error taxonomy.

    This module defines direct-import-only errors for execution availability and fallback boundaries. It intentionally imports no execution providers or optional runtimes.

    Classes

    NameDescription
    ExecutionCapabilityErrorDescribe an unavailable, unsupported, or invalid execution request.
    ExecutionCapabilityReasonClosed reason codes for execution capability errors.
    FallbackDisallowedErrorReport a fallback request outside its permitted boundary.
    InvalidExecutionStateErrorReport an invalid state for an execution request.
    UnavailableDeviceErrorReport a device that is unavailable for execution.
    UnavailableExecutionTargetErrorBase category for unavailable execution targets.
    UnavailableRuntimeErrorReport an execution backend whose runtime is unavailable.
    UnknownBackendErrorReport a backend identifier that is not recognized.
    UnknownDeviceErrorReport a device identifier that is not recognized.
    UnknownExecutionTargetErrorBase category for unknown execution targets.
    UnsupportedCapabilityErrorReport an execution capability that is not supported.
    UnsupportedExecutionRequestErrorBase category for unsupported execution requests.
    UnsupportedProcessErrorReport an execution process that is not supported.
