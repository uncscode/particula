    particula.execution.prepared

    Owned preparation, execution and observation of native Warp simulations.

    Construction is routed through runnable preparation. Primary arrays and process sidecars remain private and resident until an explicit observation. Warp CPU is an explicit regression target; requesting CUDA never falls back to the CPU.

    PreparedSimulationclass#

    View source
    class PreparedSimulation()

    Own a fixed-layout simulation and its explicit CPU observation boundary.

    Use a runnable’s prepare method to construct this object. step and run enqueue work without downloading state. synchronize waits for pending work, and snapshot returns detached CPU data for analysis. Closing waits for outstanding work and releases owned storage without an automatic download. Instances serialize their own operations.

    capturemethod#

    View source
    def capture() -> None

    Record one CUDA timestep without executing it or advancing time.

    This explicit setup boundary synchronizes prior work. Later step/run calls replay the owned graph. Shape, process order, duration and buffer identities stay fixed; forcing updates may change values in place. Warp CPU rejects. Warp may instantiate its executable on first replay; performance measurements should warm up that replay separately.

    checkpointmethod#

    View source
    def checkpoint() -> SimulationCheckpoint

    Observe and save exact continuation bytes plus frozen configuration.

    Unlike a CPU snapshot, this in-memory checkpoint preserves random streams, GPU-only fields and step counters. Resume on the same device through the original runnable or an equivalently configured sequence.

    update_environmentmethod#

    View source
    def update_environment(temperature=None, pressure=None, saturation_ratio=None) -> None

    Replace specified environment fields between run segments.

    Temperature [K] and pressure [Pa] accept scalars or per-box vectors. Saturation accepts a scalar, full-gas vector or box-by-gas matrix; it is externally prescribed when no condensation model is present. With condensation, saturation is derived and cannot be prescribed here. This explicit forcing boundary waits for prior work and its uploads. Invalid values reject before any resident field is changed.

    update_gasmethod#

    View source
    def update_gas(concentration) -> None

    Replace full-gas concentration [kg/m³] between run segments.

    Accept a full-gas vector or box-by-gas matrix in gas_names order. This explicit boundary waits for pending work, uploads owned values, and refreshes derived saturation when condensation supplies its law. It leaves particle state and process configuration unchanged.
