    particula.execution.communication

    Declare and preflight fixed-shape resident communication maps.

    This concrete-only, direct-import boundary performs read-only map validation of caller-owned Warp map arrays. It neither reads resident primaries, copies map payloads, nor launches a writer, and is deliberately absent from particula.execution exports. Empty and all-disabled maps are successful write-free cases only after complete applicable carrier, schema, alias, and domain preflight.

    Map validation validates topology and rates in 1/s, but receives neither source inventory nor time step. Population-dependent outbound-overdraw validation therefore belongs to gas transport, before its writers launch. Volume evolution owns volume writers, particle transport owns Particle transport, and resident binding owns resident binding and primary/sidecar aliasing. This module provides none of those operations, synchronization, host conversion, fallback, or scheduling.

    class CommunicationConfiguration(communication_map: CommunicationMap, prescribed_volume: PrescribedVolumeUpdate, resource_shapes: tuple[CommunicationResourceShape, ...])

    Combine immutable communication declarations without binding a session.

    The configuration preserves nested carrier and Warp-array identities, has no session or registry binding, and carries no resident primary state. It neither reads source population nor accepts a time step, so it cannot validate population-dependent outbound totals; gas transport must do so before its writers run.

    CommunicationMapclassdataclass#

    View source
    class CommunicationMap(form: CommunicationMapForm, transport_mode: CommunicationTransportMode, edge_capacity: int, source_boxes: object, destination_boxes: object, enabled: object, rates: object)

    Retain fixed-capacity caller-owned map arrays by identity.

    The frozen carrier keeps the supplied array objects, rather than copies or normalized replacements. During validation, source_boxes, destination_boxes, and enabled must be distinct, nonoverlapping, same-device contiguous pointer-backed wp.int32 arrays of shape (E,). rates must be a similarly distinct wp.float64 (E,) array in 1/s. Validation neither normalizes nor mutates these arrays.

    validate_communication_configurationfunction#

    View source
    def validate_communication_configuration(configuration: object, dimensions: object, device: object) -> CommunicationConfiguration

    Read-only validate one fixed-shape communication configuration.

    The validator retains and returns the exact configuration object. It writes no caller-owned array or carrier and makes no payload copy; private status and duplicate-detection scratch are permitted. Map index and flag arrays must be same-device, contiguous, pointer-backed wp.int32 arrays with shape (E,); rates must be wp.float64 (E,) in 1/s. Optional final volumes must be wp.float64 (B,) in m³. Array identities and nonempty half-open byte ranges must not overlap.

    Parameters

    NameTypeDescription
    configurationobjectExact immutable map, optional-volume, and resource-shape carrier.
    dimensionsobjectExact resident dimensions; only n_boxes (B) is used.
    deviceobjectExplicit active Warp device metadata for all payload arrays.

    Returns

    CommunicationConfiguration
    The exact unchanged configuration object.

    Raises

    TypeError
    If outer carriers or device metadata are invalid.
    ValueError
    If array schema, identity ownership, byte-range aliasing, value domains, or enabled topology is invalid.

    Notes

    Empty and all-disabled maps still receive full applicable preflight and are write-free on success. This validates map topology and rate domains only. It has neither source-inventory nor time-step input and cannot validate outbound population totals; gas transport must enforce that condition before writers run.
