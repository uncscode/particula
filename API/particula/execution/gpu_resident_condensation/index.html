      GPUResidentCondensationclass#

      View source
      class GPUResidentCondensation(aerosol, strategy, *, device, method='ros3', **kwargs)

      Bases: GPUCondensationODE

      Run RK23 or material-coupled ROS3 with all adaptive decisions on CUDA.

      Construction uploads native state once and captures a conditional trial loop without advancing it. advance(bound) launches that loop; accepted state, clock, retry count and step size remain on device. Only completed observation-boundary control metadata is downloaded. snapshot() is an explicit full-state download. No Warp CPU or host-control fallback exists.

      Environment is constant between explicit bounds. Arbitrary host forcing callbacks are rejected; callers may update environment at segment bounds. Tolerances and physical units match GPUCondensationODE. CUDA conditional graph support (Toolkit and driver >=12.4) is required.
