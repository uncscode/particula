# Reproduce the independent cavity tracer export

The host is OpenCFD OpenFOAM v2312, build `c39a0f64-20231220`, double
precision with 32-bit mesh labels. All three runs use an original case
generated by [prepare.py](prepare.py). Native dictionaries, boundary
conditions, initial fields and solver logs remain in the chosen case
directory. The case inputs, exporter and generated fixture carry the
[repository MIT license](../../../license).
[OpenCFD passive-scalar solver](https://doc.openfoam.com/2312/tools/processing/solvers/rtm/basic/scalarTransportFoam/)

## Generate and export

From the repository root, choose a fresh scratch directory and run the frozen
Linux image. Python with NumPy handles the export. The image below contains
both the original solver and its source.

```bash
case_dir=$(mktemp -d)
recipe=studies/prescribed-flow/openfoam-cavity
image=opencfd/openfoam-default@sha256:097e45046a74ee1dae3e6135df0c42723ba55092d246e7c9932f3bfa1e89b7b2
python "$recipe/prepare.py" "$case_dir"
docker run --rm --network none --cap-drop ALL --security-opt no-new-privileges \
  --user "$(id -u):$(id -g)" --mount "type=bind,src=$case_dir,dst=/work" \
  --workdir /work --entrypoint /bin/bash "$image" \
  -c 'source /usr/lib/openfoam/openfoam2312/etc/bashrc && bash /work/run.sh'
python "$recipe/export.py" "$case_dir" "$case_dir/export"
sha256sum "$case_dir/export/cavity.npz" docs/data/prescribed-flow-cavity/cavity.npz
```

## What the files contain

The cavity measures 0.1 × 0.1 × 0.01 m. A 1 m/s lid moves in the positive
x direction over fluid with kinematic viscosity 0.001 m²/s. Each run evolves
the velocity and kinematic pressure from rest to 0.5 s with `icoFoam`,
then freezes the pressure-corrected face flux `phi` and velocity `U`.
At 0.5 s the passive scalar is 10⁻⁶ kg/m³ in the rectangle
0.025–0.05 m in x and 0.0625–0.0875 m in y, and zero elsewhere. The lid
and walls are impermeable, with zero normal scalar gradient. The front and
back form an OpenFOAM `empty` patch. The inventory includes their physical
separation of 0.01 m. There is no source term.

`scalarTransportFoam` calls the tracer field `T`. Its dimensions in this
case are kg/m³. Both the imposed scalar diffusivity of 10⁻⁵ m²/s and the
face rates are fixed during scalar evolution. For every accepted scalar step,
[export.py](export.py) checks the written face field against the original
pressure-corrected values and the velocity against its frozen value. It checks
native dimensions, wall and empty patch types, accepted indices and timestep
widths. The transfer over an interval is precisely its native face rate
times its duration. Each internal face occurs once, positive outward from
its recorded owner. The empty-direction transfer is zero.

| Case | Mesh | Flow spin-up step | Tracer step | Tracer steps |
| --- | --- | --- | --- | --- |
| Reference | 16 × 16 × 1 | 1 ms | 2 ms | 40 |
| Half timestep | 16 × 16 × 1 | 1 ms | 1 ms | 80 |
| Refined mesh | 32 × 32 × 1 | 1 ms | 1 ms | 80 |

The [fixture](../../../docs/data/prescribed-flow-cavity/cavity.npz) keeps
reference cell IDs, centres and volumes from the solver, the ordered face
geometry and addressing, boundary IDs, velocity, kinematic pressure, signed
face fluxes, 41 scalar snapshots, native step numbers, times and interval
widths. It also contains the two refinement fields at the reference output
times, conservatively coarsened in physical volume. The
[metadata](../../../docs/data/prescribed-flow-cavity/cavity.json) records the
hash, units, thermodynamic assumptions and numerical envelopes computed before
the Particula replay. There is no density conversion in the tracer balance.
The absolute aerosol pressure is prescribed independently of kinematic pressure.
The [worked replay](../../../docs/studies/validation/prescribed-flow/cavity_replay.py)
uses these two fixture files offline.
