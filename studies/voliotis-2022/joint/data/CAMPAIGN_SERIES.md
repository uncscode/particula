# SOA and precursor trajectories across the Manchester campaign

[campaign_observations.csv](campaign_observations.csv) contains 8,282 timestamped values beyond the α-pinene study packet. The 27 EDFs originate from 16 additional chamber records. Each CSV row carries the Table 1 run ID, variable, seconds since the run's relative time origin and source value. Variable names ending in `_fraction` denote dimensionless fractions of initial α-pinene, o-cresol or isoprene remaining. The aerosol variable `soa_ug_m3` is the archived organic mass in µg m⁻³. Forcing and evaluation should use only times inside the corresponding measured windows. [Article, Table 1 and Fig. 2–3](https://acp.copernicus.org/articles/22/14147/2022/) · [Data DOI lookup, Supplement Table S1](https://acp.copernicus.org/articles/22/14147/2022/acp-22-14147-2022-supplement.pdf)

The [channel audit](campaign_channels.csv) records native column names, units, header description, retained sample counts, temporal extent and missing cells for every series. The VOC archive entries use dimensionless/unspecified units (a dash) and Table S1 describes them as fractional decay. They start near 1 and follow irregularly shaped trajectories. The records do not supply absolute calibrated organic mixing ratios for these runs. Multiplying by nominal dose gives an assumed absolute concentration with the paper's ±15% injection uncertainty. Minute sampling of the archived VOC curves is finer than the GC-MS acquisition interval. Use the processed histories as forcing. Marginal early increases above one occur in some series. The CSV leaves them unchanged.

The parser preserves column positions in ragged tab-separated rows. Blanks and declared missing-value sentinels are excluded rather than converted to zero. Run 22 has 15 o-cresol entries beyond the last valid time field. These untimed numbers are excluded and the count is recorded. Run 22's measured o-cresol fraction is already 0.852 at time zero, and α-pinene rises as high as 1.141. Its VOC record is dated 15 July in filenames while the second ancillary DOI listed in Table S1 for run 22 points to files dated 23 July. A run-specific joint gas/ancillary analysis should resolve that misalignment before combining signals. [Run 22 VOC DOI](https://doi.org/10.25326/5NXY-WN10) · [Listed ancillary DOI](https://doi.org/10.25326/XE37-GC95)

Some single/mixed EDF free-text descriptions disagree with the publication. Run 10's AMS header calls it isoprene although the paper lists o-cresol and the VOC column is explicitly `half_cresol`. Run 12's generic VOC column is assigned to isoprene by its single-precursor experiment identity and the paper. Other mixture files have copied description strings, whereas the component columns and Table 1 agree. Runs 10 and 16 VOC headers give a 1904 calendar epoch, and run 13 states seconds without an absolute date. Their numerical time starts at zero with unreacted precursor and spans the normal experiment interval. The exported numeric relative times are retained. The AMS and gas measurements are instrument-processed series with no pointwise uncertainties in these EDFs.

Some Table 1 peaks differ from the native time series. For example, the run 23 maximum is 33.26 µg m⁻³ in the AMS and 51.4 µg m⁻³ in Table 1. Other discrepancies include run 10 (23.57 versus 22.8), run 15 (10.14 versus 9.4), and run 24 (59.05 versus 58.0). Report either the archived or the Table 1 comparator explicitly. Runs 11–13 report all-zero AMS series. Run 19 has −0.33 µg m⁻³ at lights-on, run 20 has −0.01 µg m⁻³ at lights-on, and run 21 has −49.47 µg m⁻³ at 21,384 s (outside five hours). All are retained as reported. The measurement source does not distinguish instrument noise from a source error in the run 21 sample. [Run 23 archive](https://doi.org/10.25326/28KM-B382) · [Published endpoints](campaign_peaks.csv)

## Rebuild

Run `python prepare_campaign.py --raw-dir /tmp/voliotis-campaign` from this directory to query the DOI-matched archive records, retrieve their AMS/VOC EDFs, check their source SHA-256 hashes and regenerate the long data table, channel audit and [direct URL and checksum manifest](campaign_source_manifest.csv). The parser requires only Python's standard library. The Manchester data center displays the [CC BY 4.0 licence](https://creativecommons.org/licenses/by/4.0/); the CSVs reformat the team’s preliminary v1 EDF files.
